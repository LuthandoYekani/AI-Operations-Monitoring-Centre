# Sample Data

This directory contains example workflow execution payloads used to demonstrate the AI Operations Monitoring Centre.

## Files

- **healthy.json** – Normal workflow execution with a health score of 100.
- **warning.json** – Degraded workflow with minor validation issues.
- **critical.json** – Failed workflow that triggers automated incident creation and AI analysis.

These datasets can be imported into n8n to test the workflow without requiring live production systems.
